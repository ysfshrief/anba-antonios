# منصة القديس الأنبا أنطونيوس التعليمية

منصة تعليمية عربية تفاعلية عن حياة القديس **الأنبا أنطونيوس** (أبو الرهبان)، على شكل
**رحلة داخل الدير**: يصعد المتعلّم من بوابة الدير محطةً محطة، يشاهد فيديو كل مرحلة،
يجتاز اختبارها، ثم ينال شهادة إتمام في النهاية.

بُنيت بـ **React + Vite + Tailwind CSS**، مع **Firebase Firestore** (اختياري)،
ودعم كامل للعربية (RTL) وتصميم **Mobile-First**.

## ▶️ التشغيل

```bash
npm install
npm run dev        # التطوير
npm run build      # الإنتاج (مجلد dist)
npm run preview    # معاينة الإنتاج
```

النشر جاهز على **Vercel** مباشرة. ملاحظة: الـ prompt ذكر Netlify، لكن اخترنا Vercel حسب طلبك.
للنشر على Netlify أضف ملف `_redirects` فيه: `/*  /index.html  200`.

## 🗺️ خريطة الصفحات

| المسار | الصفحة | الوصف |
|--------|--------|-------|
| `/` | الرئيسية | Hero + خريطة الدير التفاعلية (SVG) |
| `/lesson/:id` | الدرس | فيديو + ملخص + ملفات + اختبار + تنقل |
| `/certificate` | الشهادة | نموذج الاسم ثم شهادة قابلة للتحميل PDF/PNG |

| `/references` | المراجع | قائمة المراجع |
| `/admin` | لوحة الإدارة | إدارة كل المحتوى (محمية بكلمة مرور) |

## 🔥 مخطط قاعدة البيانات (Firestore)

الموقع يعمل بدون Firebase (وضع Demo محلي). لتفعيل Firestore، املأ `.env` (انظر `.env.example`).
يستخدم الموقع **مستندًا واحدًا** يجمع كل المحتوى (لتقليل الطلبات وتحسين الأداء):

```
site/ (collection)
  └── content (document)
      ├── home:       { title, subtitle, churchName, ctaLabel }
      ├── lessons:    [ { id, order, stage, title, description,
      │                   youtubeUrl, summary,
      │                   pdfs:[ {name,url} ], audios:[ {name,url} ] } ]
      ├── quizzes:    { [lessonId]: [ { q, options:[...], correct } ] }
      ├── team:       { title, members:[...] }
      └── references: [ "...", "..." ]
```

> تقدّم المستخدمين يُحفظ محليًا (localStorage) لتقليل طلبات Firebase.

### 🔒 ملاحظة أمنية مهمة
كلمة مرور لوحة الإدارة موجودة في الكود حسب المتطلبات. **في تطبيق فرونت-إند فقط لا يمكن
إخفاء كلمة المرور تمامًا** (أي شخص يفتح أدوات المطوّر قد يراها). لحماية بياناتك فعليًا مع
Firebase، **اضبط Firestore Security Rules**. مثال:

```
match /site/{doc} {
  allow read: if true;
  allow write: if request.auth != null;
}
```
للأمان الكامل يُنصح لاحقًا بالانتقال إلى Firebase Authentication للأدمن.

## 🔑 لوحة الإدارة
- لا يوجد رابط ظاهر. اضغط على **اسم الكنيسة في الفوتر** → تظهر نافذة كلمة المرور.
- كلمة المرور: `01062432084` (تُغيَّر من `src/context/AuthContext.jsx`).
- تتيح تعديل: الرئيسية، الدروس (إضافة/حذف/ترتيب)، روابط يوتيوب، ملفات PDF وصوتية
  (روابط Google Drive)، الاختبارات، فريق «من نحن»، والمراجع.

## ⚙️ قواعد الرحلة
- **قفل الدروس:** لا يُفتح درس إلا بعد اجتياز اختبار السابق.
- **بوابة الفيديو:** لا يُتاح الاختبار إلا بعد مشاهدة ٩٠٪ من الفيديو.
- **النجاح:** ٢ من ٣ إجابات صحيحة (قابل للتعديل في `seed.js`).
- **الشهادة:** تُتاح بعد إتمام كل الدروس، وتُحمَّل PDF أو PNG.

## ⚡ الأداء

- الخريطة SVG خفيفة (بلا صور). محتوى الموقع في مستند واحد.
