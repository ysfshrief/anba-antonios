# رحلة مع القديس الأنبا أنطونيوس

موقع تعليمي بسيط وأنيق يعرض سلسلة فيديوهات عن حياة وتعاليم القديس الأنبا أنطونيوس —
**كنيسة رئيس الملائكة الجليل ميخائيل بدمنهور**.

بُني بـ: **React + Vite + Tailwind CSS**، بدعم كامل للعربية (RTL) وتصميم Mobile‑First،
مع خلفية Firebase Firestore (اختيارية) أو ملف JSON بسيط.

---

## ▶️ التشغيل محلياً

```bash
npm install
npm run dev
```

## 🏗️ البناء والنشر

```bash
npm run build      # يُنتج مجلد dist
npm run preview    # معاينة نسخة الإنتاج
```

الموقع جاهز للنشر مباشرة على **Vercel** (اربط المستودع واضغط Deploy — بدون إعدادات إضافية).

## ➕ إضافة أو تعديل الفيديوهات

### الطريقة الأسهل: ملف واحد فقط

افتح الملف: `src/data/videos.js` وأضف كائناً جديداً بالحقول التالية:

| الحقل        | الوصف |
|--------------|-------|
| `title`      | عنوان الفيديو |
| `description`| وصف قصير |
| `driveUrl`   | رابط Google Drive العادي: `https://drive.google.com/file/d/FILE_ID/view` |
| `thumbnail`  | رابط صورة مصغّرة (اختياري — اتركه `""` لصورة افتراضية أنيقة) |
| `duration`   | المدة، مثال: `"٥:٣٠"` |
| `order`      | ترتيب الظهور (الأصغر أولاً) |
| `visible`    | `true` للإظهار، `false` للإخفاء |

> يتم ترتيب الفيديوهات تلقائياً حسب `order`، وتُعرض فقط التي `visible: true`.
> **ملاحظة:** تأكد أن إعداد مشاركة الفيديو على Google Drive = "أي شخص لديه الرابط".

## 🔥 تفعيل Firebase Firestore (اختياري)

الموقع يعمل بدون Firebase. إذا رغبت في إدارة الفيديوهات من Firestore بدل الملف:

1. أنشئ مشروعاً على Firebase Console.
2. أنشئ مجموعة (Collection) باسم `videos`، وكل مستند يحتوي الحقول:
   `title, description, driveUrl, thumbnail, duration, order, visible`.
3. انسخ إعدادات المشروع إلى ملف `.env` (انظر `.env.example`).

بمجرد وجود `API_KEY` و `PROJECT_ID`، سيقرأ الموقع تلقائياً من Firestore،
وإلا فسيعتمد على `src/data/videos.js`.

## ✨ المزايا

- تصميم مستوحى من أديرة الكنيسة القبطية (بيج / رملي / بُني / خمري / ذهبي).
- صلبان زخرفية تتحرك ببطء في الخلفية، وفواصل قبطية بين الأقسام.
- حفظ تقدّم المشاهدة محلياً — يظهر «تمت مشاهدة هذا الفيديو ✓».
- تشغيل الفيديو داخل الصفحة (بدون مغادرتها) عبر معاينة Google Drive.
- Lazy Loading، Skeletons أثناء التحميل، معالجة الأخطاء، وجاهزية SEO.
- دعم كامل للـ RTL و Mobile‑First.
